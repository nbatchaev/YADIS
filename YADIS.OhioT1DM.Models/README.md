# YADIS.OhioT1DM.Models

Data models (DTOs) for the **OhioT1DM** dataset annotated for **XML** and **MessagePack** serialization.

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://github.com/nbatchaev/YADIS/blob/main/LICENSE)

[![NuGet](https://img.shields.io/nuget/v/YADIS.OhioT1DM.Models.svg?logo=nuget)](https://www.nuget.org/packages/YADIS.OhioT1DM.Models)

## Overview

The library defines the root `OhioT1DmPatient` model along with strongly-typed event models covering CGM readings, insulin deliveries, meals, self-reported events, and Basis wearable sensor streams.

## Usage

```bash
dotnet add package YADIS.OhioT1DM.Models
```
